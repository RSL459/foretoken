# Release 描述模板

将模板复制到 GitHub Release 描述中，替换占位内容并删除不适用的章节。按用户关心的领域归纳变更，根据已确认的贡献记录致谢。

产物表填写实际发布的版本，粘贴完整镜像地址、Chart 地址及附件下载链接。完整变更记录使用两个发布 tag 之间的 GitHub Compare 链接。
